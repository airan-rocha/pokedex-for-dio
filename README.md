# Pokedex - 1ª Geração de Pokémons

### Veja quais são os pokémons da 1ª geração e suas principais informações obtidas pela PokéAPI.

Essa aplicação WEB foi construída em sua maior parte com javascript afim de acessar/obter as informações dos Pokémons direto da PokéAPI.
Essa aplicação utiliza uma interface muito agradável e com várias informações relevantes para os usuários, como na imagem abaixo.
